# Notebooks

This folder contains Jupyter notebooks used for data exploration,
preprocessing, model experiments, evaluation and visualization.

## Planned Notebooks

1. `01_era5_exploration.ipynb` - Explore the ERA5 dataset.
2. `02_data_preprocessing.ipynb` - Prepare data for model experiments.
3. `03_model_evaluation.ipynb` - Evaluate and compare forecasts.
4. `04_hyperlocal_adaptation.ipynb` - Investigate local adaptation
   of foundation-model forecasts.
